# GPT GAS Plugin

Plugin המאפשר ל-GPT לנהל דאטה־בייס של Google Sheets דרך Google Apps Script.

## הוראות התקנה

1. העלה את כל הקבצים לתיקיית GitHub ציבורית (למשל gpt-gas-plugin).
2. הפעל GitHub Pages מתוך ההגדרות תחת Settings → Pages.
